# DIDRAKON IAM 디자인 기준

관리 콘솔(`admin/`)과 IAM 로그인 화면(`backend/iam-authn/.../templates`, `static/iam-login`)이 함께 따른다.

## 방향

| 항목 | 내용 |
|---|---|
| 제품 | 조직의 사람과 시스템의 계정·권한을 관리하고 모든 변경을 기록하는 보안 콘솔 |
| 성격 | 정확함, 차분함, 책임이 분명함 |
| 모드 | 작업형(Operate). 익숙한 패턴과 일관성이 표현보다 우선한다 |
| 참고 | Okta·Microsoft Entra·Ping (왼쪽 메뉴 + 상단 검색, 같은 정보 구조 반복, 장식 최소화, 색 수 축소, WCAG AA) |
| 고유 디테일 | **출처 표식**: 권한이 어디서 왔는지(직접·조직·그룹·JIT·위임·비상·시스템)를 고정폭 글꼴의 작은 테두리 표식으로 모든 화면에서 같게 보여준다. 이 표식은 다른 용도로 쓰지 않는다 |

## 토큰 (`src/app/globals.css`)

색은 중립 회색 단계 하나와 강조색 하나로 만든다. 화면 배경·면·선·글자는 모두 회색 단계에서 가져온다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `canvas` | `#f6f7f7` | 페이지 바탕 |
| `surface` | `#ffffff` | 표·폼이 놓이는 면 |
| `panel` | `#eff2f1` | 사이드 메뉴·표 머리·보조 면 |
| `line` | `rgb(19 26 25 / 0.09)` | 기본 선(헤어라인) |
| `line-strong` | `rgb(19 26 25 / 0.18)` | 입력란 테두리 |
| `ink` | `#131a19` | 본문 글자 |
| `ink-2` | `#46514f` | 보조 글자 |
| `ink-3` | `#66706e` | 흐린 글자 (흰 바탕 대비 4.9:1) |
| `accent` | `#1f5c55` | 주요 버튼·선택 상태·핵심 숫자만. 흰 글자 대비 7.4:1 |
| `accent-hover` | `#174a44` | 주요 버튼 hover |
| `accent-soft` | `#e5efed` | 선택된 메뉴·행 바탕 |
| `field-line` | `#80898a` | 입력칸(입력·선택·여러 줄) 테두리만. 흰 바탕 대비 3.58:1 — 입력칸 경계는 비텍스트 대비 3:1 이상이어야 해서 `line-strong`(1.5:1)을 쓰지 않는다 |
| `danger` / `danger-soft` | `#b42318` / `#fbeceb` | 오류·회수·거부 |
| `success` / `success-soft` | `#1d6a43` / `#e6f2eb` | 허용·활성 |
| `warning` / `warning-soft` | `#8a5300` / `#fbf0dc` | 주의·재검토 |

- 그라디언트, 빛 번짐, 색 있는 그림자, 유리 효과는 쓰지 않는다.
- 상태 색은 의미가 있을 때만 쓴다 (활성·거부·재검토). 장식으로 쓰지 않는다.

## 글자

- 한 가족: **Pretendard Variable** (자체 호스팅). 숫자·ID·코드·시각은 `font-mono` 와 고정폭 숫자.
- 크기: 12(메타) · 13(표·레이블) · 14(본문) · 16(구획 제목) · 20(페이지 제목). 굵기 400·500·600 만.
- 위계는 크기와 색으로 만든다. 대문자 영문 코드(`ACTIVE` 등)는 화면에 그대로 내보내지 않고 한글 레이블로 바꾼다 (`src/lib/labels.ts`).
- 짧은 문구(제목·버튼·레이블)는 마침표 없이 쓴다. 느낌표는 쓰지 않는다.

## 간격·모양

- 4px 격자. 사이드 메뉴 240px, 메뉴 행 32px, 표 행 40px, 입력란 36px.
- 모서리: 입력·버튼 8px, 면 12px. 그림자는 쓰지 않고 헤어라인으로 구분한다.
- 같은 종류는 같은 크기: 모든 목록 행, 모든 면의 안쪽 여백(20px)이 같다.

## 화면 뼈대

- 왼쪽 메뉴(현재 위치 표시) + 상단 막대(전역 검색, 로그아웃).
- 목록 화면: 제목 → (추가 버튼으로 펼치는 생성 폼) → 목록.
- 상세 화면: 제목·상태·핵심 메타 → 구획들(항상 같은 순서: 기본 정보 → 관계 → 권한 → 기록).
- 생성 폼은 목록 아래에 늘 펼쳐 두지 않고 `추가` 버튼으로 펼친다.
- 되돌리기 어려운 작업은 확인을 받는다. 오류는 원인과 다음 행동을 함께 쓴다.

## 상호작용

- 모든 조작 요소에 hover·focus·disabled·처리 중 상태가 있다. 키보드 포커스 링은 강조색 2px.
- 움직임은 색·바탕 변화 150ms 뿐. 반복 애니메이션·튀는 효과 없음.
- 텍스트 선택색·스크롤바·체크박스 색도 토큰에서 가져온다.

## 마크와 움직임

| 항목 | 기준 |
|---|---|
| 마크 | 마주 보는 두 용(인증·인가)이 열쇠 구멍(문)을 지킨다. 원본 `src/components/brand-mark.tsx`. 파비콘 `src/app/icon.svg`, 로그인 화면 `static/iam-login/icon.svg`·`templates/fragments.html` 이 같은 경로 데이터를 쓴다 (모양을 바꾸면 네 곳을 함께 바꾼다) |
| 색 | 마크는 강조색 하나. 눈은 바탕색과 같게(`--mark-eye`). 어두운 바탕·타일에서는 흰 마크 |
| 크기 | 콘솔 왼쪽 위 30px, 로그인 76px, 파비콘은 타일(잉크 청록 바탕)을 거의 채운다 |
| 움직임 | 업무 화면은 움직이지 않는다. 입장하는 순간(첫 로그인 화면)에만 한 번: 두 용이 떠올라 마주 보고 열쇠 구멍이 열린다 (약 0.9초). `prefers-reduced-motion` 이면 재생하지 않는다 |
